# 施工单：给「修不了的表格」插 HTML 指针（**还没动手**）

> **这份文档是给一个新会话看的。** 它自带全部背景 —— 不要假设读者知道之前发生过什么。
> 写于 2026-10-09。**一个字都还没改。**

---

## 一、要干什么

前面几批把**能修的**表都修了（普通压平表 3,642 张、合并格 362 + 233 张、口径外 744 张）。
**剩下的修不了。** 修不了的这些，不再硬塞进 markdown —— 而是在 md 里**那张表的位置**加一句
**指向上游 HTML** 的注释，让读者/agent 直接去读那张真表。

**这就是「指针」**：不假装能表达，而是**把「md 答不了 + 去哪儿查」写准**。

> **它和「转录说明」是同一套规矩的两处应用**（见 `schema.md` **§1.3**）：
> 固定措辞 + 自我声明「非原文」+ 指确切文件。§1.3 结尾已经写明这一层关系。

## 二、为什么现在能做（两个前提都已满足）

1. **上游 HTML 已入库** —— `raw/`（9,321 个 `.htm`）2026-10-09 已 git commit
   （commit 那个加 raw 的提交（已在 2026-10-10 分仓改写中抽掉）），并且 `.gitattributes` 把 `*.htm` 标了 `-text`（**按字节原样存**）。
   → 「真结构见 raw/xxx.htm」这句话**有东西可指，而且那个东西不会变**。
2. **规格已立** —— `schema.md` **§1.3** 授权修复器在语料里加固定措辞的说明。

## 四、两级锚 —— ★ 定位靠这个，不靠格子

**关键**：锚**不是表格里的格子**（那才是「太短 / 有歧义」的原因），
而是**表格外面的散文** —— 段落通常长、而且独特，好找。

1. **一级锚：表前那段文字。**
   上游 HTML 里**每张表前面总有段文字**（一句说明，或一个小标题），
   而 md 是整篇转过来的 —— **那段文字在 md 里也在**。
   → 拿它去 md 里找 → 找到在哪一行 → **表就在它下面** → 指针插在它后面。
2. **二级退路**：表前没文字时（直接跟在上一张表后）→ 用**它前面的小标题**；
   再不行 → 用**它上面那张表**。

**⚠️ 一个必须记住的技术细节**：匹配要**按「段落 / 行」做**，**不能按「第几个字符」做** ——
比对时会把空格换行全抹掉，抹掉之后字符位置**对不回原来的行号**。
所以找的是「**那段话说在哪一行**」，不是「第几个字符」。

## 五、插在哪、长什么样

**位置：插在压平块的上方**（紧接「表前那段文字」之后）。
—— 与「转录说明」相反（那个在表格**下方**）。理由：读者应该**先**看到「这张表表达不了，去这儿看」，
而不是先啃一段读不出结构的乱麻。

**措辞（草案，待批 —— 按 §1.3 必须固定且写进 `schema.md`）：**

```
> ⚠️ 表格指针（非原文）：本表 markdown 表达不了。真表见 `tdc-html/raw/<topic>.htm`
> 中**第 <N> 个有格子的 `<table>`**（跳过 `<table id="vr">` 空壳）：<R> 行 × <C> 列<形形状补充>。
```

- `<N>` 按**文档顺序**数；**要写明「有格子的」** —— 否则读者数 `<table` 会把
  `<table id="vr">` 那个空壳也数进去，**差一位就全指错**。
- 形状补充：含 `colspan` / `rowspan` / 嵌套表，有什么写什么。
- **原压平文本一个字不删**（已批）—— 注释只是**加一句**，不是替换。

## 八、坑（前面几批真踩过的，直接继承）

- **换行**：一律 `read_bytes()` / `write_bytes()`。Windows 上 `read_text` 会抽 CR、`write_text` 会加 CR。
- **`core.autocrlf=true`**：`git show HEAD:` 出来的是 LF，而清单里的偏移是**工作区字节偏移**
  —— **逐字节重放前必须对齐换行**，否则 100% 误报（2026-10-08 踩过）。
- **写含反引号的内容** → 用 Write 工具，**别用 shell heredoc**（本工程踩过至少五次）。
  本次指针措辞**含反引号**，尤其注意。
- **别把「工具再跑 = 0 可修」当"做完了"的证据** —— 2026-10-09 已推翻过这条：
  候选口径本身不可信时，那个 0 是「看不见」不是「没有」。
- **参数化前先用 `--limit` 试点**，别直接全量 `--apply`。
