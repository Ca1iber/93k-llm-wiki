# 未修清单 —— 建页那一轮撞出来的东西

**写于 2026-09-28。** 背景：为了补 93 个「页面伸手要、但那页不存在」的对象，
建了 93 页并写了散文。**建的过程撞出一批本不在计划里的问题**，这份是它们的账。

**格式**：它是什么 / 证据在哪 / 影响面 / **判据做好了没有** / 代价 / 谁定。

---

## 零、总闸现状

**第十五类已经绿了**（93 页散文全部写完、无骨架占位符）。
**唯一还红的是第十四类**，原因是**两件没做的事**：

| 没做的事 | 为什么没做 |
|---|---|
| `index.md` 没列这 93 页 | 每页要一行**钩子**（一句人写的话），93 行得先写出来 |
| `index.md` 会超 §7 的 25,000 token 预算 | 实测 23,216，只剩 1,784；93 行约 +5,000 → **必超** |

**§7 对超预算的规定是「拆子索引」**，而拆会牵动第十四类的判据
（它得知道「这一节的清单在另一个文件里」）。
**这是整件事的收尾，也是最该先做的一件** —— 见 **D1**。

## A. 语料层（要 §1.2 那套流程：先摆证据 → 经批准 → 改 → 记 log → 重跑 extract）

### A1. **乱码族 3,220 处 / 605 篇 —— 上游有正字，可修**（最大的一件）

- **是什么**：`鈮?` / `鈥慸` / `鈥?` 这类坏字（§11.2 ①）。工程原来记的是
  「第三字节被 `?` 替掉，**不唯一**，不许当映射用」，**判定不可修**。
- **新证据**：`findings-mojibake-upstream-resolves.md`。
  核上游 `.htm`：**605 篇里 602 篇的上游是干净的（99.5%），上游也坏的 0 篇。**
- **判据做好了没有**：**没有。** 现在只做到**按篇**（这一篇的上游干不干净），
  **没做到按处**（md 里那一处 ↔ 上游里那一段）。**这是动手前必须先解决的。**
- **代价**：3,220 处，比之前修的上标那批（151 处）大 20 倍。改 md 还是改 raw 要先定。
- **谁定**：**你。** 这是语料改动，且量大。

### A2. `## Related information` 链接粘连 —— 25 处

- **是什么**：`[A](<x>)[B](<y>)` 两个链接首尾相接、无分隔符。
- **证据**：`dfut` / `setup-level-set-0` 两组**各核过上游** —— 上游是三个独立
  `<div><a>`（`dfut` 还带 `title=` 提示语），**分隔是转换丢的**。
  `shared-continuity-test` 那组**第三次**核出同一结论。
- **判据**：**做好了**（正则 + 上游对照），全库 **25 处 / 25 篇 = 0.3%**。
- **代价**：小。**这条现在就可以直接做。**

### A3. `.Note ` 粘连 —— 336 处，**待定**（判据没做对）

- **是什么**：`…is 0.Note setup_time has…`（句号后直接接 `Note`，无分隔）。
- **上游长什么样**：`chosen submenus.<div class="note">…` —— 上游确实是块元素紧跟文字、
  源码里原本没有空白；**渲染时是另起一段，转换把它拍平了**。
- **判据做好了没有**：**没有。定位脚本不可信**：336 处里 **218 处根本没定位到**，
  已定位的部分分类也不可靠（抽样里标成「内联」的其实是块元素）。
- **所以现在的数不能拿去改语料。**
- **它卡在跟 A1 同一个前置问题上。**

> **A1 和 A3 共用一个前置**：那份「按处映射」的判据（md 里那一处 ↔ `.htm` 里那一段）。
> **做出来一次，两条都能定。所以它该排在 A1/A3 前面，单独当成一件事做。**

### A4. `DC/DC power units` —— **不是转换坏的，救不回来**

- 上游 `.htm` 里就是这样（应作 `index`），全语料 **128 篇**含该串。
- 属 §11.2 ⑤（上游就坏）。**只能记，不能改。** 已记。
- 同类：`PinPropertyMonitor` 的 Example 里 `ppm1` 声明四次、`pinList` 未声明 ——
  **上游逐字相同**，照抄会编不过，已在页上 ⚠️ 标明。

## B. 检查器的洞（不动语料，改的是判据）

### B1. **第七类不看含中文的引文块 —— 1,418 块 / 27.6%**

- **证据**：`findings-quote-checker-holes.md`。实测 wiki 里 5,129 个 `>` 引文块，
  **1,418 个含中文、一律不被检查**。这工程的页面本来就是中文写的，**混排越自然越不在范围内**。
- **不是理论风险**：第四批有个 agent 的三页引文**全部含中文 → 全不被查**，
  它自跑一遍规范化核验，**抓出自己 4 处错**（标题/空格/漏 `content=`/大小写与截断）。
- **判据**：改它要想清楚「CJK 块里哪部分是引文、哪部分是作者的话」——**机器分不出来**，
  这正是当初排除它的理由。
- **可能的解法**：规定一种**引文边界的写法**（例如引文必须独立成块、作者的话不许与引文同段），
  让机器能切。**这是写法约定，不是正则。**
- **谁定**：你。**代价**：全库 1,418 块从此受检，**可能一次报出很多。**

### B2. **第七类的两道余量叠在一起 → 放过了一处真缺陷**

- **证据**：`findings-quote-checker-holes.md`。`hardware-bin-summary-tab` 那处
  「自称逐字、丢了 20% 内容」**全绿通过**：① `cov >= 0.8` 是闭区间；② 它认不出
  `**原文逐字（…）：**` 这个写法，于是「自称逐字」计 0、按宽松标准判。
- **新形态**：不是一条判据窄，是**两条判据的余量叠在一起**。
- **判据**：**没改。** 改法两条（收紧阈值 / 认全自称写法），都是改判据。
- **谁定**：你。**建议先看清「自称逐字」在页面上有多少种写法**再决定认哪些。

### B3. **`ERR_MIN = 60` 静默丢掉 33 处真材料**

- **证据**：`findings-scaffold-syntax.md` 末尾。命中 `Errors`/`Warnings`/`Limits` 的段 495 处，
  **33 处短于 60 字符被挡**，挡掉的是实义内容（好几条是**否定式**：「越界**不**报错」）。
- **判据**：做好了（`objpack.sections_of()`，注意**不是** `verbatim_sections()`）。
- **两条修法，取舍不同**：
  ① **降门槛**（或去掉，靠已有的 `is_stub` 挡空壳）→ 33 处立刻回来，
     但**改的是全库 229 页的报错节**，要重刷 + 重验第十二类；
  ② **不降门槛，只让报告说出被丢了什么** → 不动页面，但 33 处**还是不在页面上**。
- **谁定**：你。**两条可以都做，顺序你定。**

### B4. **缺一个「逐页引文自查」的正规工具**（新，从第四批观察到的）

- 写页的 agent 被要求自查引文，**四个批次里至少 5 个 agent 各自临时写了一遍**
  （复刻 `verify_stages` 的 `_norm` / `_extract_quotes`）。
- **而它们复刻的时候，把 B1 那个洞也一起复制了**（`if … re.search(r'[一-鿿]', q): continue`）。
  有一个连临时文件都留在了仓库里（`extract/_qcheck_tmp.py`，**已删**）。
- **要的不是「再来一份复刻」，是一份**：① 命令行能对单页跑；② **不跳 CJK 块**；
  ③ 对不上时打印**缺了哪一段**（现在只报覆盖率）。
- **代价**：小，而且**它是 B1 的前置** —— 有了它，B1 改判据时才有对照。
- **谁定**：要做的话我可以直接做（这是新写工具，不是改既有判据）。

## C. 抽取器认不出段 —— 8 种形状（语法节 / 报错节内容缺失）

- **证据**：`findings-scaffold-syntax.md`。已知 8 种：描述性标题（`svlr` / `term`）、
  笔误（`jsdf` 的 `## JDSF`、`msdf` 的 `## MDSF`）、空标题 + 签名写在下一行（`dcdt`）、
  根本没有段标记（`built-in-functions`）、标题只给一套形态（`sldo`）、
  **`## Errors` 短于 `ERR_MIN` 被丢（`sldo`，同 B3）**。
- **判据**：**收不了，而且不是「放宽阈值」能收的**：
  - 认描述性标题 → 得回答「哪些 H2 算语法段」，**判宽了就是把散文当语法抄进页面**；
  - 容忍笔误（编辑距离 ≤ 1）→ **`DFPN`/`DFPS`/`DFPT`/`DFUP`/`DFUT` 这一族（8 个真命令，
    全都只差一个字母）立刻互相误配。**
- **该做的是「报告口径」那一半**：让脚本报告「**我认出了哪些段、没认出哪些、哪些因为太短被丢**」。
  现在它只报「过期 N 处」，**N=0 时看起来像「全都对」，而其实可能是「什么都没认出来」**。
- **谁定**：先做报告口径（**成本低、无风险**），再谈要不要扩充识别。

## D. 页面 / 规格层

### D1. **`index.md` 拆子索引 + 93 行钩子** —— 卡着总闸，**建议第一件做**

- **为什么**：第十四类是**唯一还红的**；不做完，「十五类全绿」永远差一块。
- **两件**：① 给 93 页各写**一行钩子**；② 按 §7 把对象节拆到 `wiki/objects/index-objects.md`。
- **§7 已经把规矩写死了**：子索引叫 `index-<类型>.md`、**放在那个类型的目录里**、
  根 `index.md` 只留一行指针；**「只有 `index.md` 自己撑爆预算时才拆」** ——
  现在正是这个条件（23,216 + 93 行 > 25,000）。
- **代价**：要改**第十四类的判据**（让它知道清单在另一个文件里）——**这是唯一有技术风险的一步。**
- **谁定**：机制 §7 已经定了；**要不要现在做，你定。**

### D2. 61 处「未建」要改措辞

- **是什么**：建页把已有页面里「`[[x]]`（未建）」变成了假话。工程自己的
  `fix_unbuilt_marks.py` **只删能证伪的**：6 处已删、11 处在引文里一个字不动、
  **61 处要人改措辞**（形状不明确 / 删了会丢信息）。
- **判据**：工程的判据已经做好了（可惜只覆盖能证伪的那部分）。
- **代价**：61 处措辞，是**写作活**，可以按页派。**谁定**：做不做、什么时候做。

### D3. `PROSE-SPEC.md` 两条要改

1. **「不要读 `sources` 之外的文档」这条不成立。** 已撞到 3 页
   （`smartest-data-formatter` 的 `sources` 是纯索引、`hardware-view` 用法全在子主题里、
   `match-loops` 主篇只有 35 行；第四批 `pin-property-monitor` 又是同一形状）。
   **要改成**：「`sources` 是纯索引 / 只是壳时，可读它自己声明的子主题，
   但必须在 `## 出处` 里逐条声明」。
2. **把「核上游 `.htm`」写进规格。** 第三批六个组有**四个**主动做了，
   **两次推翻先前的判断**（`鈮?` 由「不可修」改成「可修」；`DC/DC power units` 由疑似改成确证）。
   **在此之前，好几条只能写「判不了」。** 这是这次最有价值的一条做法沉淀。
- **代价**：改规格，小。**谁定**：你。

### D4. 语法节那句样板话**在说谎**

- 它写「定义文档里没有 `Syntax`/`Parameters`/`Example` 这类**段标记**」，
  而那几篇**有 `## Example`**，只是整段只剩图片、被 `is_stub` 挡掉了。**理由是错的。**
- **代价**：改 `objscaffold.py` 里那句文案（按「真正的原因」分几种说法）。**谁定**：你。

### D5. `refresh()` 打印的符号是反的

- 印「整页 X → Y 字符，−N」，那个 N 是 `len(改前) − len(改后)` —— **页面变长时是负的**，
  于是「`115,885 → 138,305`，`-22,420`」里箭头和数字**互相打脸**。
- **代价**：一行。**当时没顺手改是因为 §1.2 的「不许顺手改旁边」。**

## E. 建议顺序（理由排序，不是难度排序）

1. **D1（拆子索引 + 93 行钩子）** —— 唯一卡着总闸的一块，且是这轮建页的**收尾**。
2. **B4（逐页引文自查工具）+ B3/C 的报告口径** —— 都是**低成本、无风险**，
   做完之后「哪些引文没查、哪些段没收」**从静默变成有数**。
   而且 B4 是 B1 的前置：改判据之前得先有对照工具。
3. **A 的前置：那份「按处映射」判据** —— 做出来一次，**A1（3,220 处）和 A3（336 处）同时解锁**。
   在此之前，那两条只能停在「知道有这回事」。
4. **A1（乱码族）** —— 最大的一笔，但要等第 3 步。
5. **B1 / B2（检查器的洞）** —— 是规格决定，**做完才知道会不会一次报出很多东西**，
   所以放在改语料之前（否则改完语料又冒出一批新红）。
6. **A2（链接粘连 25 处）** —— 判据已好、代价小，**可以随时插空做**。
7. **D2（61 处措辞）/ D3 / D4 / D5** —— 散活。

**一句话**：**先把总闸收拾干净（D1），再把「静默」变成「有数」（B4/B3/C），
然后做那份按处映射的判据（解锁 A1 + A3），最后才动语料。**
