# Data navigation views

#### Subtopics

- [Test summary tab](<02.08.04.13.03.02.01_Test_summary_tab.md>)

- [Table filter](<02.08.04.13.03.02.06_Table_filter.md>)

The data navigation section of the Result perspective contains one data navigation view for each opened data store. Each data navigation view contains up to five tabs that display different kinds of summaries for the data store:

- [Test summary](<02.08.04.13.03.02.01_Test_summary_tab.md>)
- [Wafer summary](<02.08.04.13.03.02.02_Wafer_summary_tab.md>) (not present for [correlation data stores](<02.08.04.13.02.02.04_Correlating_data_logs.md>))
- [Device summary](<02.08.04.13.03.02.03_Device_summary_tab.md>) (not present for correlation data stores)
- [Hardware bin summary](<02.08.04.13.03.02.04_Hardware_bin_summary_tab.md>)
- [Software bin summary](<02.08.04.13.03.02.05_Software_bin_summary_tab.md>)

Note that the views are static for data log files (their content does not change), but the view system data log stream is dynamic: If new data log entries are generated by a running test, they are immediately added to the open log. The summaries and result displays are updated accordingly.

 ![Data log summary view_Annotated view](<../../../../raw/137559.png>)

## Toolbar

There is a toolbar for the data navigation views that is displayed as part of the main SmarTest toolbar:

 ![Data log summary view_Toolbar](<../../../../raw/136461.png>)

The toolbar contains buttons that let you group the test summaries displayed in the frontmost tab of the data navigation views. Grouping means that each summary, instead of being displayed in one row, is split up into one row for each subcategory. For example, if a test summary table is grouped by site, the results for each test that is summarized in the table are displayed separately for each site instead of all together in one row.

These buttons are available for [test summary tabs](<02.08.04.13.03.02.01_Test_summary_tab.md>):

- ![Data log summary view_Toolbar, Refresh button](<../../../../raw/144663.png>) Refresh. Updates the system data log stream display with the latest logged data when it is paused (see below), but does not turn on automatic updating again, like Resume does.

This button is available only if the frontmost tab is the test summary tab of the system data log stream.

- ![Data log summary view_Toolbar, Pause button](<../../../../raw/136494.png>) Pause. Pauses updates from the system data log stream. For details, see the Pause shortcut menu command in [Test summary tab](<02.08.04.13.03.02.01_Test_summary_tab.md>). If this button is clicked, it changes to Resume (see below).

This button is available only if the frontmost tab is the test summary tab of the system data log stream.

- ![Data log summary view_Toolbar, Resume button](<../../../../raw/136495.png>) Resume. Resumes updates from the system data log stream. For details, see the Resume shortcut menu command in [Test summary tab](<02.08.04.13.03.02.01_Test_summary_tab.md>). If this button is clicked, it changes to Pause (see above).

This button is available only if the frontmost tab is the test summary tab of the system data log stream.

- ![Data log summary view_Toolbar, Clear button](<../../../../raw/144664.png>) Clear. Removes all current entries from the system data log stream display in the Integrated Result Tool and clears the system event stream.

This button is available only if the frontmost tab is the test summary tab of the system data log stream.

- ![Data log summary view_Toolbar, Clear and Save button](<../../../../raw/144665.png>) Save and Clear. Displays a standard Save dialog in which you can save the current system event stream as an EDL file. After you have saved the file, all current entries from the system data log stream display in the Integrated Result Tool are removed and the system event stream is cleared.

This button is available only if the frontmost tab is the test summary tab of the system data log stream.

- ![Data log summary view_Toolbar, Group by Site button](<../../../../raw/136462.png>) Group by wafer
- ![Data log summary view_Toolbar, Group by Site button](<../../../../raw/136463.png>) Group by site

Grouping by site is also available from the shortcut menu of [hardware bin summary tabs](<02.08.04.13.03.02.04_Hardware_bin_summary_tab.md>) and [software bin summary tabs](<02.08.04.13.03.02.05_Software_bin_summary_tab.md>) (though the toolbar button is disabled in these views).

- ![Data log summary view_Toolbar, Group by Pin button](<../../../../raw/136464.png>) Group by pin

If the frontmost tab is not a test summary tab, the buttons are disabled.

The data navigation section of the Result perspective contains one data navigation view for each opened data store. Each data navigation view contains up to five tabs that display different kinds of summaries for the data store:

- [Test summary](<02.08.04.13.03.02.01_Test_summary_tab.md>)
- [Wafer summary](<02.08.04.13.03.02.02_Wafer_summary_tab.md>) (not present for [correlation data stores](<02.08.04.13.02.02.04_Correlating_data_logs.md>))
- [Device summary](<02.08.04.13.03.02.03_Device_summary_tab.md>) (not present for correlation data stores)
- [Hardware bin summary](<02.08.04.13.03.02.04_Hardware_bin_summary_tab.md>)
- [Software bin summary](<02.08.04.13.03.02.05_Software_bin_summary_tab.md>)

Note that the views are static for data log files (their content does not change), but the view system data log stream is dynamic: If new data log entries are generated by a running test, they are immediately added to the open log. The summaries and result displays are updated accordingly.
