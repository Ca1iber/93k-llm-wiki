# 待处置：页里的「（**未建**）」标记，很多已经过期

发现时间：2026-09-21（收尾第十四类时顺查出来的）
发现方式：查「页已存在、行内却仍称未建」的对撞——**十五类检查一个都不管这件事**。

## 现象

**67 个文件、约 156 处**，页里写着 `[[x]]（**未建**）`，而 `wiki/` 下 `x.md` **已经建好了**。
最典型的形状：

| 形状 | 处数 |
|---|---|
| `（**未建**）` | 101 |
| `（**均未建**）` | 16 |
| `（未建）` | 6 |
| 其余（带解释的，如「与本页同批建」「但允许清单里有」「前者未建」…） | 33 |

**成因**：写页时那页确实没建，作者把「未建」当**快照**写进了正文；
后面批次把页建起来了，**没有任何一步回头改这些标记**。

> **口径说明**（上面 156 与下面的 163 对不上，是**单位不同，不是两次数矛盾**）：
> 上面这张表是**按「行」数**的（一行里只要有一条链接已有页就记一次），
> 下面处置表是**按「括号」数**（一行里有两个过期的括号就记两次）。**两个数各说各的，别混用。**

## 为什么十五类全绿也看不见它

十五类查的是：格式齐、引的文档存在、引文逐字、候选有归宿、**链接不悬空**、
命名合规、层一致、脚本段新鲜、版本页可回溯、index 与目录互相覆盖、散文写过了。

**这一条恰好落在所有判据的缝里**：

- **第八类**查的是「链接指不到东西」——这里**恰好相反**：链接指**到了**，
  所以第八类不会报。**「指得到」和「说它指不到」是两件事，只有后者是错的。**
- **第七类**管引文逐字，不管散文里的判断。
- **第十四类**管 `index.md` 这个手写文件的自我声明，不管 412 个页面的正文。

所以它是**第六种「检查比它自称的范围窄」**的形状：
**判据查的是「有没有悬空」，而错的是「声称悬空」——错在反方向。**

## 复核办法

```bash
cd F:\master-dev\understand-anything-wiki
python -X utf8 -c "
import re, pathlib
have = {p.stem for p in pathlib.Path('wiki').rglob('*.md')}
n = 0
for p in sorted(pathlib.Path('wiki').rglob('*.md')):
    for i, ln in enumerate(p.read_text(encoding='utf-8').split(chr(10)), 1):
        if '未建' not in ln: continue
        for m in re.finditer(r'\[\[([^\]|]+)\]\]', ln):
            if m.group(1).strip() in have:
                n += 1; print(p.relative_to('wiki').as_posix(), i, m.group(1)); break
print('处数', n)
"
```

## 处置 —— **2026-09-21 已做，结果如下**

工具：`extract/fix_unbuilt_marks.py`（判据写死在代码里，可试跑、可回退）。
原文件备份在 `extract/.unbuilt-bak/`（逐字节）。

| 处置 | 处数 | 判据 |
|---|---|---|
| **删掉括号** | **99** | ① 括号**紧跟在某一条 `[[x]]` 之后**，且那条链接**已有页**；② `（**均未建**）`，且它管到的**全部**链接都有页 |
| **跳过：在引文里** | **9** | 括号落在 `>` 引用块、反引号跨度或 `「」` 里——**一个字不动** |
| **留给人改措辞** | **55** | 其余一切形状 |

**「跳过」那一条是这一轮加的，它是铁律**：`objects/device-directory.md` 有两处是在
**引用另一页的原话**（`依据：该页自己写着 \`[[device-directory]]（未建）— 产物\``），
删掉括号就是**把引文改了**——**而第七类正是查引文逐字**。另一处整行是 `>` 块，
讲的恰好就是「那句话是它写的时候的状态」，删了等于把这条说明自己抹掉。

**留下的 55 处不是「没做完」，是「机械改不了」**，分三种：

1. `` `名字`（**未建**） `` ——**反引号里是文档/工具名，不是 wikilink**。
   它「建没建」要看**文档标题到页面的映射**，不是「有没有同名页」。**判不了就别删。**
   （例：`` `Saving test numbers as TMLimits CSV files`（**未建**） ``）
2. `（**未建**，与本页同批建）`、`（**未建**，slug 在清单里）`、`（**尚未建页**，是悬空目标）` ——
   **括号里带着解释，删掉会连信息一起丢**，要改措辞。
3. `（**前者未建**）`、`（**后两个未建**）` ——**相对位置的说法**，
   要先判断「哪一个现在建了」，才能改。

**顺序**：已改完 → 重跑十五类（**退出码 0**）+ `.pagecheck.py`，再 `snapshot.py`。

> ⚠️ `.quoteverify.py` **不能当判据用**：它报 949 条「对不上」，
> 抽三条回 raw 核过——**一条在 raw 里真的有**（那是它自己的归一化不够），
> 两条是**页面自己写的中文摘要**（`>` 块不一定是引文）和**页面记录自己初版错译**的引文。
> **949 条里没有一条是页面的错。** 第七类（会跳过语法节、按词窗算覆盖率、只看自称「逐字」的）
> 才是这一项的判据，它 ✅。
