### Syntax

```
UDPT {(portlist)}
```

### Parameters

|

portlist

 |

List of port names or the symbol @@, which undefines all ports. If more than one port is to be removed, the names must be separated with a comma.

 |

### Example

```
UDPT (port_1)
```

This command undefines port port_1.
