# 版本页 — Index

**这个目录回答「这个功能哪一版才有 / 哪一版变了」。**

- 全部条目**原样转录自语料的 `## Functional changes` 段落**，由 `extract/versions.py` 机械分组，**零 LLM**。
- **每页只说明「文档这么写」**，不说明「机台这样」（schema §11）。
- 机器可读全量：`extract/version-facts.csv`（`product, version, kind, text, doc, line`）。

**`kind` 三态**：`change` = 该版改了什么；`intro` = 该版新引入；`base` = 文档范围之前就有（**只有 6.3.2 一个哨兵值**，见该页说明）。
