## 是什么

**一句话：Test Number Generator 是「给测试发号」的模块，它图的是 `consistently`（一致）——号发出来之后落在 TMLimits 文件里。** 原文前两句：

> 「The Test Number Generator is a software module that can be used either from the SmarTest GUI or by calling its APIs from a user-written test method to consistently number tests for data logging and evaluation purposes.」

> 「The test tables generated by it are stored in TMLimits files. Test tables can contain arbitrary information in addition to test numbers and limits.」

**这两句把五件事定死了**：

| 原文的片段 | 说的是什么 |
|---|---|
| `a software module` | 它**不是一个 GUI 窗口，也不是一个函数**，是一个模块 |
| `either from the SmarTest GUI or by calling its APIs from a user-written test method` | **两条入口**：GUI 侧 / test method 侧 |
| `to consistently number tests` | **目的**：给测试发**一致的**编号 |
| `for data logging and evaluation purposes` | **用途**：data logging 与评估 |
| `stored in TMLimits files` | **落点**：TMLimits 文件 |
| `can contain arbitrary information in addition to test numbers and limits` | **表里不止编号和限值**——**可以有任意自定义列** |

**最后一条是本页最值钱的一句**：**这张表不是「编号 + 上下限」的定长结构**。本页「语法 / 参数」节里的例子正好是这句话的实例——**第二个代码块就是第一个代码块里插进一列 `Status` 之后的同一张表**（那一节是子主题 `02.10.01.08.01.01.03.01` 的文本，**本页没有打开那一篇**，见「出处」）。
